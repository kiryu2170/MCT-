# MCTオイル タイプ診断アプリ

イベント会場のタブレットで使う、タッチ操作の診断コンテンツです。
「①興味喚起 → ②タイプ選択 → ③タイプ別の使い方提案 → ④購入誘導」の4画面構成。

- `index.html` … アプリ本体（1ファイルで完結）
- 画像はすべて Base64 で HTML 内に埋め込み済み（外部通信・Wi-Fi不要で動作）
- 45秒間タッチ操作がないと、自動で①の画面に戻ります（イベント運用向け）

## タブレットでの運用メモ

- 会場のタブレットのブラウザで公開URLを開く
- 「ホーム画面に追加」しておくと、アドレスバーが目立たずアプリのように使えます
- 誤操作防止のため、ガイドアクセス機能（iPad：アクセスガイド／Android：画面固定）の利用を推奨
- Wi-Fiが不安な場合は、`index.html` をタブレットに直接保存して開くオフライン運用も可能です

## 今後の更新について
